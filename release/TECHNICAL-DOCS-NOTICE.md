# Canonical Technical Specification

The complete canonical technical specification named by the referring operator
guide is maintained in the SPITFIRE NG source repository. It is intentionally
not duplicated in this compact operator archive.

This Development Preview contains the executable-version-specific public
workflow under `docs/operator/`. Use the release's operator procedure for
installation, configuration, operation, backup, restore, and rollback. Obtain
the matching repository revision before changing implementation contracts or
developing extensions.
