# Local Historical Research Samples

This directory is intentionally empty in the public repository.

Historical SPITFIRE binaries, registered copies, manuals, DISPLAY resources,
archives, and companion programs may be useful as read-only research inputs,
but they are not covered by the SPITFIRE NG project license and must not be
committed here.

The repository `.gitignore` excludes everything below `research/samples/`
except this policy file. Contributors must use only material they are legally
entitled to inspect and must not redistribute it through issues, pull requests,
fixtures, screenshots, or release packages.

Public original software and documentation are maintained separately at
[Original SPITFIRE Software & Documentation](https://spitfirebbs.com/).

Use synthetic, project-authored fixtures for public tests. Independently
written format findings and hashes may be documented under `docs/` when they
do not reveal private registered data or reproduce copyrighted content.
