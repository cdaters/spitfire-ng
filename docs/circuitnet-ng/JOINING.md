# Joining CircuitNET NG — operator workflow

Agree a unique Node ID, parent HOST, network/profile identity, contact method and
poll expectations with the network operator. Obtain the explicit tree and approved
codenames. Create local native conferences and map codenames deliberately; this
proposal does not create or number conferences for you.

Configure the profile and your role, enroll neighbor certificates, then Test Link.
Request your own desired subscriptions from your direct HOST. With the default
policy, wait for its operator's approval and confirm the typed result. Choose an
exchange Event: Hybrid for prompt outbound work plus catch-up, Scheduled for an
arranged window, or Manual for deliberate Poll Now. An END can receive HOST mail
by initiating its own Poll; an inbound listener is not required at that END.

See the [END](END-NODE.md), [HOST](HOST-NODE.md) and [ROOT](ROOT-NODE.md) guides.
