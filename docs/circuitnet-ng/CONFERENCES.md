# CircuitNET NG conference catalog

Catalog revision 2. Generated from the signed catalog.

Catalog availability does not create a local conference or subscription.
Local numbers and access rules remain each BBS's responsibility.

SUPPORT is core and Sysop-only. SYSOP, SPITFIRE and DOORS are optional
and Sysop-only. Verified visiting Sysops may receive locally granted access;
ordinary callers receive no privileges from catalog membership.

## REQUIRED NETWORK CONFERENCES

Required on every participating board. Preserve each area's access rules.

### SUPPORT - CircuitNet Support

Network operations notices, support, approved changes and participating Sysop questions.

Requirement: Required on every participating board.
Status: active.
Access: Sysops and verified visiting Sysops; granted locally.

### CHITCHAT - General Chit-Chat

General conversation connecting callers across participating boards.

Requirement: Required on every participating board.
Status: active.
Access: Callers authorized by local conference rules.
