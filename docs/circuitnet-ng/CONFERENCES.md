# CircuitNET NG conference proposal — review draft

This proposal is **not an official adopted catalog**. No conferences, native
mappings, moderator appointments or subscriptions are created automatically.
The historical reconciliation retains 60 active areas, five deletions and six
unapproved proposals. Modern choices below are independent of those historical
facts. All 71 records have an explicit disposition, including proposals for which
no historical codename is known. Preserve does not reenact historical conduct or
identity-disclosure rules. Rename changes a display name; codenames remain stable.
Merge requires a published migration decision, never a silent routing alias.

The [proposed catalog](config/conferences.proposed.json) contains 46 candidate
definitions, including two clearly marked new proposals (PROTOCOL and RETRO).
Undecided, merged and archived records are omitted from that import candidate.
[Complete dispositions](config/historical-dispositions.proposed.json) retain every
historical area for review. No local SPITFIRE conference numbers or database IDs
occur in these formats. Other BBS implementations can map the same codenames to
their own native conferences. A future importer must validate uniqueness, format
version and explicit operator mapping; it must not enable areas by default.

Security, age/access and moderation decisions remain open for review. Topics with
special audience or advice concerns are marked Undecided rather than silently
inventing network policy. All conference content is readable under destination
BBS access rules; directed routing does not create secrecy.
