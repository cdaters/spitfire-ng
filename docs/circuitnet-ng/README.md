# CircuitNET NG Network Kit 1.0

CircuitNET NG connects independent BBS systems through shared message conferences
and file distribution. This kit contains the network's Charter, Rules, conference
list, joining information and operator guides. It contains no BBS software binaries.

## Start here

Read [ABOUT](ABOUT.md) for the network layout and terms, then
[GOALS](GOALS.md), [CONFERENCES](CONFERENCES.md) and [FILES](FILES.md).

To join, read [RULES](RULES.md), [CHARTER](CHARTER.md) and
[JOINING](JOINING.md). Check [JOINING-INFO](JOINING-INFO.md) before completing
[APPLICATION](NODE-APPLICATION.md).

Already assigned a Node ID? Follow [END-NODE](END-NODE.md) from enrollment to
an exchange. Operators serving other boards should also read
[HOST-NODE](HOST-NODE.md) or [ROOT-NODE](ROOT-NODE.md).

## Find a document

The archive opens with README.TXT. Its other top-level TXT files are the BBS
editions. Markdown editions are in markdown/. Configuration examples and the
signed conference catalog are in config/. Protocol specifications are in technical/.

[SECURITY](SECURITY.md) explains certificates, message visibility and verification.
[KEY-CUSTODY](KEY-CUSTODY.md) covers catalog signing-key recovery.
[OPERATIONS](OPERATIONS.md) contains command conventions and troubleshooting.

RELEASE.TXT identifies this build. MANIFEST.sha256 and MANIFEST.json list its
contents. See [VERIFICATION](VERIFICATION.md) before using the catalog or examples.
